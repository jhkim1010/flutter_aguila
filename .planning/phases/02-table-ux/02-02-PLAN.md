- TBL-01: 칼럼 헤더 클릭 정렬 (이미 기존에 동작, 변경 없음)

검증 항목:

**1. 정렬 확인 (TBL-01):**
   - 아무 칼럼 헤더를 클릭 -> 오름차순 정렬 확인 (화살표 아이콘)
   - 같은 헤더를 다시 클릭 -> 내림차순 전환 확인

**2. 필터 확인 (TBL-02):**
   - tipo 드롭다운에서 값 선택 -> 데이터가 필터링되는지 확인
   - 텍스트 검색창에 키워드 입력 -> 데이터가 좁혀지는지 확인

**3. 페이지네이션 확인 (TBL-03):**
   - 테이블 하단에 페이지네이션 컨트롤이 보이는지 확인
   - 첫 페이지에서 "이전" 버튼이 비활성화인지 확인
   - "다음" 버튼 클릭 -> 2페이지 데이터 로드 + 페이지 번호 "2 / N" 표시 확인

   - 페이지 크기 드롭다운에서 50 선택 -> 50행 표시 + 첫 페이지로 복귀 확인
   - 페이지 크기 200 선택 -> 200행 표시 확인
   - 정렬 변경 후 페이지 번호가 1로 초기화되는지 확인
   - 필터 적용 후 페이지 번호가 1로 초기화되는지 확인
   - 페이지 이동 시 테이블이 상단으로 스크롤되는지 확인
